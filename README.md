# 🏋️‍♂️ Async Telegram Gym Assistant Bot

A fully asynchronous Telegram bot designed for fitness tracking, full-body workout guidance, and physical metrics calculation. 

## 🚀 Key Features
- **Smart Gym Guide:** Provides tailored exercises for major muscle groups (Chest, Back, Legs) via custom interactive reply keyboards.
- **Warmup Calculator:** Dynamically generates step-by-step warmup sets (50%, 70%, and 90% of working weight) with integrated rest-timer advice.
- **BMI Calculator:** Collects user weight and height to compute Body Mass Index, offering custom fitness and nutrition insights.
- **Local JSON Database:** Keeps permanent profiles for users, remembering their latest stats and BMI history using a local file system.

## 🛠 Tech Stack
- **Language:** Python 3.13
- **Framework:** Aiogram 3.x (Asynchronous Telegram Bot API)
- **Deployment & Network:** Configured via custom **Cloudflare Workers** to bypass regional network blocks and ensure 100% server uptime.
- **Database:** JSON-based local data storage.
